完全に独立した、Google Sheets に依存しない編集者管理システムです。

## 🚀 クイックスタート

### 1️⃣ ローカルテスト（5分）

```bash
# ターミナルで以下を実行
cd /mnt/user-data/outputs

# Flask依存パッケージをインストール
pip install Flask

# Flaskアプリケーションを起動
python app.py

# ブラウザで http://localhost:5000 にアクセス
```

### 2️⃣ メッセージ自動抽出をテスト

```bash
# 別のターミナルで以下を実行
python editor_update_parser_sqlite.py "じぇいをテスト中に"
```

**出力例:**
```
📝 入力: じぇいをテスト中に
✅ ✅ じぇい を テスト中 に更新しました
更新日時: 2026年09月29日 19:30:00
```

Web UI をリロードして、「じぇい」のステータスが「テスト中」に変わったか確認。

### 3️⃣ インターネット公開（Render / Heroku）

**HOSTING_GUIDE.md** を参照してください。

推奨: **Render（無料・簡単）**
- GitHub にコードをアップロード
- Render で Web Service を作成
- 自動的に公開 URL が割り当てられる
- チーム全員に URL を共有

## 💬 使用方法

### Claude チャットから更新（自動）

```
メッセージを打つ ➜ Python スクリプトが自動解析 ➜ SQLite 更新 ➜ Web UI に反映
```

**例:**
```
「みつゆうを継続発注中に」
「砂田さんをテスト中に」
「全員をテスト前に」
```

### Web UI から直接更新（マニュアル）

1. Web UI にアクセス
2. 編集者を選択
3. ドロップダウンからステータスを選択
4. 「更新」ボタンをクリック
5. 1秒以内にデータベースが更新される

## 🔧 テクニカルディテイル

### Python スクリプト（自動更新）

`editor_update_parser_sqlite.py`：
- 正規表現で「【編集者】を【ステータス】に」のパターンを抽出
- 編集者名を辞書マッピングで正規化
- SQLite に直接書き込み
- 短縮名も対応

### Flask Web アプリケーション

`app.py`：
- REST API エンドポイント提供
  - `/api/editors` → 全編集者取得
  - `/api/editors/update` → ステータス更新
  - `/api/statuses` → ステータス一覧

- Web UI テンプレート
  - Bootstrap で レスポンシブデザイン
  - リアルタイムフィルタ・検索機能

### SQLite スキーマ

`editor_db.py`：
- **editors テーブル** → 編集者情報（24列）
- **status_options テーブル** → ステータスマスタ
- **division_options テーブル** → 区分マスタ

## ⚙️ トラブルシューティング

### Q: メッセージを送ったのに反映されていません

**A:** 以下を確認：
1. 編集者名が正しい（リストを確認）
2. ステータスが 8 種類の中から選択
3. 「を」が含まれている（「砂田さんをテスト中に」の形式）
4. Web UI をブラウザでリロード

### Q: Web UI が表示されません

**A:**
1. Render のログを確認（ダッシュボール → Logs）
2. ローカルで `python app.py` を実行してエラーを確認
3. Flask が 5000 番ポートで起動しているか確認

### Q: SQLite データベースが空

**A:**
```bash
# データベースを再初期化
python editor_db.py
```
